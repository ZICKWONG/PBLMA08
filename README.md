# Aplikasi Agenda Kegiatan Organisasi Mahasiswa

Halo, selamat datang di repo kami! 👋

Pernah nggak sih ada kegiatan organisasi yang jadwalnya bentrok, atau kamu harus tanya ke pengurus satu per satu buat tahu acara berikutnya kapan? Nah, web ini kami buat buat ngatasin itu. Semua agenda kegiatan dicatat di satu tempat, jadi pengurus gampang ngatur dan anggota tinggal buka web buat lihat jadwal terbaru gitu.

Proyek ini kami kerjakan di Politeknik Negeri Batam sebagai tugas kuliah. Webnya sengaja dibuat simpel karena kami masih belajar, tapi fiturnya jalan dan bisa dipakai beneran.

## Isinya apa aja?

- Pengurus bisa kelola kategori kegiatan, data anggota, dan data kegiatan (tanggal, jam, lokasi, penanggung jawab, deskripsi)
- Tiap kegiatan punya status: Direncanakan, Berlangsung, Selesai, atau Batal
- Kegiatan bisa dicari lewat nama, kategori, tanggal, penanggung jawab, atau status
- Ada rekap jumlah kegiatan dan peserta per periode
- Admin dan anggota punya login masing-masing

## Dibuat pakai apa?

HTML, CSS, dan JavaScript buat tampilan, Python buat sisi server, dan MySQL buat databasenya.
